离线 RAG 知识问答系统 (Offline RAG QA System)

💡 项目背景
基于研一自学，从零手搓的一个完全离线化、保护数据隐私的大模型检索增强生成（RAG）系统。旨在解决大模型在垂直领域（如企业私有文档）中存在的“幻觉”和“知识盲区”问题。

⚙️ 技术栈
Python, BM25, Sentence-Transformers (Text2Vec), RRF (Reciprocal Rank Fusion), Ollama (Qwen2.5), Prompt Engineering.

🚀 核心工作与优化（面试重点）
数据清洗与切分工程：针对原始维基百科文本含大量脏数据（如角标）的问题，使用正则表达式进行清洗；抛弃按句号切分，改为按段落和语义边界切分，构建了 98 个高质量 Chunk。

混合检索策略（Hybrid Search）：发现单路检索痛点——纯 BM25 无法解决同义词（如“全名”与“曾用名”），纯向量检索易受长文本语义稀释影响。因此手写实现了 RRF（倒数排名融合）算法，将两路召回结果重排。

端到端生成与幻觉控制：基于本地部署的 Qwen2.5 模型，设计了带有“防幻觉约束”的 Prompt 模板。在排查生成结果时，发现 Top-3 截断导致模型无法获取答案，通过调整上下文注入量至 Top-5，成功解决了模型“拒不回答”的 Bug，并实现了带引用的输出。

📊 实验对比结果（黄金评测集）
BM25 召回：Recall@5 极低（受限于字面匹配）。

向量召回：Recall@5 达到较高水平，但首名容易被长文本干扰。

RRF 融合后：成功将正确答案（chunk_6）顶至 Top 1，最终大模型输出完全正确且附带引用来源。
