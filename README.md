# Offline RAG Knowledge QA System (完全离线 RAG 知识问答系统)

## 📌 项目简介
本项目是基于研一自学，从零手搓的一个完全离线化（数据不出内网）的 RAG（检索增强生成）系统。旨在解决大模型在垂直领域私有文档中存在的“幻觉”和知识盲区问题。支持从脏数据清洗、混合检索到本地大模型生成与引用溯源的端到端流程。

## 🛠️ 技术栈
- **语言与框架**：Python
- **检索算法**：BM25 (jieba分词) + Dense Retrieval (Sentence-Transformers/text2vec-base-chinese) + RRF (倒数排名融合)
- **生成模型**：Ollama 本地部署 Qwen2.5 模型
- **工程实现**：正则表达式清洗、结构化 JSON 切分、Prompt 防幻觉约束设计

## 🚀 核心工作与优化
1. **数据清洗与切分**：针对原始文本含大量引用角标（如 `[73]`）的脏数据，使用正则替换清洗；改按段落与句子边界切分，合并过短碎片，生成 98 个高质量 Chunk，有效缓解“长文本语义稀释”问题。
2. **混合检索架构**：手写实现 RRF 算法，将基于字面匹配的 BM25 与基于语义的向量检索融合。成功解决了纯 BM25 无法召回同义词（如“全名”与“曾用名”）的痛点。
3. **Prompt 工程与 Bug 排查**：设计了“找不到答案直接拒答”的防幻觉 Prompt。在调试中发现 Top-3 上下文截断导致模型拒答，通过将注入量调整至 Top-5，成功实现精准回答与 `【chunk_x】` 的溯源引用。

## 📊 实验对比
*(注：可根据你的实际终端截图补充)*
- **纯 BM25**：Recall@5 极低，受限于词频死板匹配。
- **纯向量检索**：Recall@5 较高，但首名极易被长文本干扰。
- **RRF 融合**：成功将正确文本块（如 `chunk_6`）稳定排至 Top 1，大模型生成准确率 100%。
